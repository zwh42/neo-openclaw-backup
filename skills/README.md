# 已安装技能索引

## 安装命令

```bash
# Scrapling 系列
skillhub install scrapling-official
skillhub install scrapling-web-scraping
skillhub install scrapling-fetch

# AI Search Hub (克隆自 GitHub)
git clone https://github.com/minsight-ai-info/AI-Search-Hub.git ~/.openclaw/workspace/skills/AI-Search-Hub

# 依赖安装（AI Search Hub 需要）
pip install playwright --break-system-packages
playwright install chromium

# 微信文章抓取依赖
pip install miku_ai camoufox[geoip] --break-system-packages

# 其他技能（skillhub）
skillhub install agent-reach
skillhub install find-skills
skillhub install github
skillhub install obsidian
skillhub install pdf pdf-tools pdf-extract
skillhub install self-improving-agent
skillhub install summarize
skillhub install suno
skillhub install tavily-search
skillhub install weather
skillhub install md2wechat md2wechat-skill
skillhub install tencentcloud-lighthouse-skill
skillhub install tencent-cos-skill
skillhub install tencent-docs
skillhub install baidu-search
skillhub install skill-security-auditor
skillhub install skill-vetter
skillhub install agent-browser
```
